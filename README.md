# GREENTEC Repository

Public software repository for the GREENTEC Facility Control System.

This repository is intended to host the static files that GREENTEC Studio and DEPOT nodes can retrieve over HTTPS.

## Public repository URL

Once GitHub Pages is enabled from the `main` branch and `/docs` folder:

`https://mugget5489.github.io/Greentec/`

## Layout

- `docs/index.json` — repository manifest
- `docs/facility.json` — public facility/repository metadata
- `docs/bootstrap/` — generated ComputerCraft bootstrap scripts
- `docs/releases/` — release manifests/packages published by GREENTEC Studio

Do not commit private credentials, access tokens, enrollment secrets, or other sensitive configuration to this public repository.
